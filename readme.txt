== Description ==

Golden Rashifal एक हाथ से कोड किया गया प्रीमियम WordPress थीम है, जो ख़ास तौर पर हिंदी राशिफल, पंचांग, चौघड़िया, राहुकाल, मुहूर्त, त्योहार और आध्यात्मिक लेखन के लिए बना है।

मुख्य बातें:

* शाही गोल्डन और सफ़ेद रंग की साफ़, पठनीय UI
* मोबाइल-फ़र्स्ट और थंब-फ्रेंडली नेविगेशन
* तेज़ लोडिंग — कम CSS, कम JS, कोई भारी फ्रेमवर्क नहीं
* AdSense-फ्रेंडली स्पेसिंग और इन-आर्टिकल विज्ञापन स्लॉट
* SEO के लिए तैयार — Article, FAQ और Breadcrumb Schema
* Rank Math और Yoast के साथ अच्छी तरह काम करता है
* पंचांग, चौघड़िया, राहुकाल विजेट
* राशिफल कार्ड, ज़ोडियक ग्रिड, त्योहार काउंटडाउन
* Gutenberg-कम्पैटिबल, अनुवाद के लिए तैयार, RTL सपोर्ट

== Installation ==

1. WordPress एडमिन में जाएँ: Appearance → Themes → Add New → Upload Theme.
2. ZIP फ़ाइल अपलोड करें और थीम Activate करें।
3. Appearance → Customize से रंग, लोगो, सोशल लिंक और होमपेज सेक्शन सेट करें।
4. होमपेज दिखाने के लिए: Settings → Reading → "A static page" चुनें और एक खाली पेज को Front Page बनाएँ। थीम का front-page.php अपने आप काम करेगा।
